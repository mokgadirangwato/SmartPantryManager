Smart Pantry Manager

About the Project

Smart Pantry Manager is an Android application developed to help users manage pantry ingredients, monitor expiry dates, and discover recipes based on the ingredients they have available.

The application provides a convenient way to organise pantry items, manage ingredient quantities, and find suitable recipes while helping reduce food waste.

This project is being developed using Android Studio as part of a Mobile Application Development practical assignment.

Features

1. Pantry Management

* View pantry items in a list.
* Add new pantry ingredients.
* Edit existing pantry items.
* Delete pantry items.
* Record ingredient names, quantities, units, and optional expiry dates.

2. Recipe Suggestions

* Browse suggested recipes based on available pantry ingredients.
* Apply strict ingredient matching to ensure recipes are suggested only when the required ingredients and quantities are available.
* Display feedback when recipes cannot be prepared because ingredients are missing.
* View recipe ingredients and preparation instructions.

3. Recipe Favourites

* Mark recipes as favourites.
* Save favourite status for supported recipes.

4. Expiry Alerts and Settings

* Configure the expiry-alert setting.
* Display warnings for expired or soon-to-expire ingredients when alerts are enabled.
* Manage application preferences through the Settings screen.

5. Data Persistence

* Store pantry ingredients and recipe information in a local database.
* Preserve saved data when the application is closed and reopened.

Technologies Used

* Java – application logic and functionality.
* Android Studio – development environment.
* Android SDK – Android application development tools.
* XML – user interface layouts.
* Room Persistence Library – local database management.
* SQLite – underlying local database.
* RecyclerView – displaying pantry items and recipe lists.
* Git and GitHub – source code version control and project management.

Application Screens

The application includes the following screens:

* Pantry Screen: Displays saved pantry ingredients.
* Add/Edit Ingredient Screen: Allows users to add or update pantry items.
* Suggested Recipes Screen: Displays recipes that match the available pantry ingredients.
* Recipe Details Screen: Displays recipe ingredients and preparation steps.
* Settings Screen: Provides access to application preferences, including expiry alerts.

Installation

1. Clone or download this repository from GitHub.
2. Open Android Studio.
3. Select Open and choose the SmartPantryManager project folder.
4. Allow Gradle to sync and download the required dependencies.
5. Connect an Android device or start an Android emulator.
6. Click Run in Android Studio to build and launch the application.

Database and Data Management

Smart Pantry Manager uses the Room Persistence Library to manage local data.

The database stores pantry ingredients and recipe information. Pantry management supports Create, Read, Update, and Delete (CRUD) operations, allowing users to maintain their pantry records.

Recipe suggestions are generated by comparing recipe requirements with the ingredients and quantities currently available in the pantry.
