Smart Pantry Manager

About the Project
Smart Pantry Manager is an Android application developed to help users manage their pantry items and browse recipes in one application.

The project is being developed using Android Studio.

Features
- View pantry items.
- Add pantry items.
- Browse recipes.
- Navigate through a user-friendly Android interface.

Technologies Used
- Java
- Android Studio
- Android SDK
- Git and GitHub

Installation
1. Download or clone this repository from GitHub.
2. Open Android Studio.
3. Select **Open** and choose the SmartPantryManager project folder.
4. Allow Gradle to sync.
5. Run the application on an Android emulator or compatible Android device.

## Project Status
This project is currently under development. More features and improvements will be added as development continues.
